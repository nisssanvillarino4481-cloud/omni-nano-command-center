# Omni Nano Command Center

A Ruby gem for managing Omni Nano Command Center operations.

## Installation

Add this line to your application's Gemfile:

```ruby
gem 'omni-nano-command-center'
```

And then execute:

```bash
$ bundle install
```

Or install it yourself as:

```bash
$ gem install omni-nano-command-center
```

## Usage

```ruby
require 'omni_nano_command_center'

puts OmniNanoCommandCenter.hello
```
